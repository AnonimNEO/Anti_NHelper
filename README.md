# Anti_NHelper
Данный репоризиторий создан в **демонстрационых** целях, а также для показа маштаба **проблемы** в защите программы *NHelper*.

**Мы не предоставляем никакой ответствености или гарантий, а также мы не распространяем никакие бинарники!**

# Дополнительная информация
Данная уязвимость работает с самой первой версии до последней (на момент написания V4.2)

*Небольшая уязвимость которая в будущем может быть более опасной*
Если схватить окно и начать ним двигать потребление ОЗУ начнёт расти вплоть до 50, 70, 100MB
А если попробывать переключать вкладки (не просто все по одному разу, а просто всё время переключать вкладки) - то потребление ОЗУ начнёт расти ещё сильнее, *лично Я смог довести потребление программы до 700MB*
возможно если программно перемещать окно или переключать вкладки - это *может* вызвать проблемы.
